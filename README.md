# Project Title: AI does add music to photos when watching a picture. 

## Summary

This is not a problem that needs to be solved but rather something that can be created. When taking a picture on the phone, Yes you can edit or download an app that can put music as background on the picture. But the older generation does not have this kind of knowledge or the time to do such a thing. So if AI could add the function "add music" when taking a picture the person can just for example choose the classic music for that picture. Music stimulates the amygdala which is an emotional center in the brain. Combining pictures with music makes memories stronger and easier to recall.  


## Background
Which problems does your idea solve? How common or frequent is this problem? What is your personal motivation? Why is this topic important or interesting?

As mentioned before this is not a problem. But it can be used in different situations: 
* Example 1: If a person just took a picture and this person had a very lovely time. After some hours this person wants to think of this moment and go back. He will not remember everything about it, after one hour he will have forgotten 50% of the situation, but by increasing the memory and activating the amygdala strongly it will be easier to recall the memory.
* Example 2: Music can help with memory loss by stimulating brain areas related to memory, emotions, and cognition. It is especially beneficial for people with conditions like Alzheimer's disease, and dementia. Music provides a powerful tool for improving memory and quality of life, even in the face of memory loss.

It is not complicated. It is very easy. It can be used in every situation and at any time when someone takes a picture.
